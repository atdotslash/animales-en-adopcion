# El PataRock - Festival Solidario 🤘🐾

¡Bienvenido al repositorio oficial de **El PataRock**! Este es un proyecto web desarrollado de forma integral para la materia **Diseño Gráfico**. Se trata de una plataforma responsive para un festival de música solidario ficticio, cuyo objetivo principal es la difusión y recaudación de fondos (100% de lo recaudado) para la ONG **Animales en Adopción Zárate**.

El sitio ya se encuentra desplegado y es completamente funcional a través de **GitHub Pages**.

---

## 🚀 Características del Proyecto

El sitio web está compuesto por 5 páginas principales y un flujo de checkout complejo altamente interactivo:

1. **Home (`index.html`):** Portada principal con estética grunge, presentación del festival, grilla dinámica de información sobre la ONG y mapa de ubicación.
2. **Line-up (`lineup.html`):** Grilla horaria y cartelera de las bandas principales del evento.
3. **ONG Rescate (`ong.html`):** Sección dedicada a concientizar sobre la labor de la organización, con llamados a la acción tanto para la compra de tickets como para la redirección al sitio web real de la ONG.
4. **Tickets (`tickets.html`):** Landing page de preventa con las diferentes opciones de pases (General, Pata VIP y Pack Familiar).
5. **Ubicación y FAQ (`ubicacion.html`):** Guía de cómo llegar al Anfiteatro Homero Expósito en Zárate y sección de preguntas frecuentes con colapsables/diseño limpio.
6. **Flujo de Checkout (`checkout.html`):** Formulario interactivo de 4 pasos (Entradas, Datos, Pago y Resumen) que procesa de manera dinámica la cantidad de pases seleccionados, calcula los totales de forma automática mediante JavaScript y simula la finalización de la compra con un mensaje de éxito.

### 📱 Optimización Mobile (Responsiveness)
* **Menú Hamburguesa:** Navegación móvil fluida optimizada mediante JavaScript nativo para evitar desbordamientos en pantallas reducidas.
* **Layout Adaptable:** Uso de CSS Grid y Flexbox para garantizar una visualización óptima en dispositivos de cualquier resolución.
* **Diseño UI/UX:** Fondo adaptado con efecto fijo (`background-attachment: fixed`) utilizando la imagen optimizada del festival para un scroll suave y estético.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de cada una de las secciones.
* **CSS3:** Estilos personalizados, variables de entorno para la paleta de colores, maquetación adaptiva (Grid/Flexbox) y efectos de transición (`hover`).
* **JavaScript (Vanilla JS):** Lógica detrás de la calculadora de tickets, flujo de pantallas del formulario y dinamismo del menú responsive.
